# MacPad++

Qui si scarica **MacPad++**, l'editor di testo per Mac. Questa repository contiene solo le
versioni pubblicate.

## Installazione

1. Scarica **[MacPad.dmg](https://github.com/vanzoedoardo-spec/macpad-releases/releases/latest/download/MacPad.dmg)**:
   il link porta sempre all'ultima versione.
2. Apri il file e trascina MacPad++ nella cartella **Applicazioni**. Aperta direttamente dal
   `.dmg` l'app non può aggiornarsi.
3. Al primo avvio macOS blocca l'app, perché non è ancora firmata da Apple. Vai in
   **Impostazioni di Sistema → Privacy e sicurezza**, scorri in fondo e clicca **Apri comunque**
   accanto a MacPad++. Serve solo la prima volta.

Funziona sui Mac con Apple Silicon e con processore Intel.

## Aggiornamenti

MacPad++ si aggiorna da solo: quando esce una versione nuova la scarica, la installa e propone di
riavviare, in fondo alla barra laterale. Se non riavvii, alla prossima apertura è già aggiornata.

Le novità di ogni versione sono nelle [release](https://github.com/vanzoedoardo-spec/macpad-releases/releases).

## Le tue pagine

Le pagine restano solo sul tuo Mac, in `~/Library/Application Support/it.archivagroup.macpad/`:
gli aggiornamenti non le toccano.
